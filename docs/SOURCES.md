# Sources and provenance

The public numerical example is independently chosen for teaching and checking the model. The data manifest identifies every supplied input file. No historical market prices, actual tax lots, transactions, fees, or manager alpha are claimed.

The accounting design can be compared with public IRS descriptions of capital-gain netting and investment income:

- https://www.irs.gov/taxtopics/tc409
- https://www.irs.gov/publications/p550

These references do not validate a particular client's tax treatment. The engine simplifies tax character, interest deductions, and liquidation. It does not implement a full tax return or the special rules for every long-short transaction.

Private project materials inform the broader research questions. The original workbook, extracted curve, source discrepancies, and source-based reference results are supplied separately to course reviewers through `RESTRICTED_DATA.md`. They are not prerequisites for running the public illustrative example.
